Context-Engineer for Local AI Agents

Zero-config RAG for Ollama. Automatic chunking, token-budget awareness, and source citation in one Python package.

# Install in 30 seconds pip install context-engineer ollama pull nomic-embed-text llama3.2 context build ./docs context query "What is the main topic?"

Built for local AI, not cloud APIs.

Most RAG tools assume you have Pinecone, OpenAI, and a fat wallet. ConText assumes you have a laptop and Ollama.

🎯

5 Auto Chunkers

Markdown, code, semantic, fixed, sliding — picked per file type. No more manually tuning chunk sizes.

💰

Token-Budget Aware

Retrieval fits chunks to your model's context window. No "context overflow" errors. No wasted tokens.

📚

Source Citation

Every answer includes [1], [2], [3] references. Trace claims back to source docs.

🚀

30-Second Setup

pip install + Ollama models + context build. That's it. No Docker, no API keys, no config files.

💾

SQLite Storage

No ChromaDB, no Faiss, no Pinecone. Just a file. Back it up, copy it, gitignore it — done.

🔌

HTTP API

Up and running in 4 commands.

# 1. Install the package
$ pip install context-engineer

# 2. Pull Ollama models (one-time, ~1GB each)
$ ollama pull nomic-embed-text
$ ollama pull llama3.2

# 3. Index your docs
$ context build ./docs

Python API.

from context_engineer import ConText

ctx = ConText(
    llm_model="llama3.2",
    embed_model="nomic-embed-text",
    context_window=8192,
)

ctx.build("./docs")
ctx.add_text("Some important info", source="notes.md")

answer = ctx.query("What is X?")
print(answer.text)        # "X is ... [1]"
print(answer.sources)     # [Source(...), ...]
print(answer.latency_ms)  # 1234

ctx.stats()
# {'documents': 5, 'chunks': 312, 'embeddings': 312, ...}
